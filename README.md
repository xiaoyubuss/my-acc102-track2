# S&P 500 Valuation Ratios and Stock Return Analysis
ACC102 Track 2 – Python Data Analysis Project

## Project Overview
This project explores the relationship between common stock valuation ratios (PE, PB, Dividend Yield) and the annualized returns of S&P 500 constituent companies. The analysis aims to help investors and finance students understand whether these metrics can be used to identify outperforming stocks.

## Data Source
- **Provider**: Yahoo Finance
- **Data Type**: Real financial metrics and annual returns of major S&P 500 stocks
- **Access Date**: April 2026
- **Usage**: The data is used for educational analysis only, and is publicly available for non-commercial use.

## Analytical Workflow
1.  Data preparation and structuring using Pandas
2.  Descriptive statistical analysis
3.  Correlation matrix to measure variable relationships
4.  Data visualization (heatmap, scatter plots, bar charts)
5.  Grouped comparison of value vs. growth stock performance
6.  Final insights and conclusion

## Key Findings
- Low PE (value) stocks delivered stable and competitive returns in the sample.
- The PE ratio showed a clearer correlation with returns than the PB ratio, making it a more practical metric.
- Dividend yield had a mild positive relationship with annual returns, indicating steady performance from dividend-paying stocks.
- Overall, reasonable valuation metrics remain effective for evaluating S&P 500 stock performance.
